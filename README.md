# Python Practice Collection

This repository contains my Python practice exercises.

The purpose of these exercises is to practice combining Python concepts together.

This calculator project was created for learning purposes. The number-to-word dictionary currently supports numbers from 1 to 9 only. This limitation is intentional because the focus was practicing Python fundamentals, not building a complete calculator.

Concepts practiced:
- User Input
- Variables
- Arithmetic Operations
- If / Elif Statements
- Lists
- Dictionaries
- For Loops
